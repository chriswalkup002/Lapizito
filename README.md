
# Lapizito

## Descripción del proyecto

Lapizito es una aplicación móvil diseñada para ayudar a los estudiantes a organizar sus actividades académicas de una manera sencilla y eficiente.

La aplicación busca facilitar la administración de tareas, exámenes y proyectos escolares, permitiendo que los estudiantes tengan un mejor control de sus responsabilidades.

## Problemática

Muchos estudiantes tienen dificultades para organizar sus actividades escolares, recordar fechas de entrega y administrar correctamente su tiempo. Esto puede provocar retrasos en las tareas y problemas para cumplir con sus responsabilidades académicas.

## Objetivo general

Desarrollar una aplicación móvil que permita organizar y administrar las actividades académicas de los estudiantes mediante herramientas de planificación, recordatorios y notificaciones.

## Características principales

- Registro y organización de tareas.
- Administración de exámenes y proyectos.
- Recordatorios de fechas importantes.
- Notificaciones de actividades pendientes.
- Integración con Google Classroom y calendarios.

## Tecnologías

El proyecto contempla el uso de tecnologías de desarrollo móvil y herramientas de integración para facilitar la organización académica.
